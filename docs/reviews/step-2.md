## Automated checks

```sh
npm run check --prefix AliceIdentityService.Admin
AIS3_TEST_ADMIN_CONNECTION='Host=/tmp;Database=postgres;Username=cysun' \
AIS3_TEST_RESTORED_CONNECTION='Host=/tmp;Database=ais3_copy;Username=cysun' \
dotnet test
dotnet format --verify-no-changes --no-restore
```

Use an AIS2 dump restored to a separate database for AIS3_TEST_RESTORED_CONNECTION. Adjust host/user as needed. Five tests create/drop isolated databases and one reads the restore in a read-only transaction. Without these variables, the six database tests are skipped. There are 26 backend tests and five frontend tests; build the frontend first so the HTTP tests can check the real admin assets.

The backend suite covers script-created table/model compatibility, readiness before/after initialization, bootstrap/repeat/failure behavior independent of migration history, Identity password-hash compatibility, OpenIddict persistence, and restored data reads.
