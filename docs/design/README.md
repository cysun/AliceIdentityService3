# Approved visual reference

`approved-mockup.html` is a preserved copy of the interactive design reviewed before AIS3 implementation. It is an HTML fragment containing inline styles/scripts for the original visual preview. It is a reference artifact, not the application or a source of real user data.

Step 1 translates the direction into Razor and React: restrained blue accents, neutral surfaces, sidebar administration, compact status badges, a split direct-login layout, and centered OIDC account pages. It also follows the operating system's light/dark preference and adapts to small screens.

The reference includes screens planned for later steps. Their presence does not imply those features are implemented. The live component page exercises the selected Base UI stack; account markup remains server-rendered.
